# 栖园

一个看起来很普通的楼盘营销网站。往下滚动，它会一点点变得不对劲，最后变成一段第一人称视角的恐怖场景。

在线地址：<https://fnyfree.github.io/qiyuan/>

纯前端单页：WebGL2 实时渲染画面，Web Audio 实时合成音效，没有依赖、构建步骤和任何网络请求。

> 本站是虚构作品。栖园、恒晖置业、7 号楼、1301 室，以及站内的人名、电话、证照编号均为虚构，与任何真实楼盘、公司或人物无关。

## 观看前须知

- 页面包含**闪烁画面、画面抖动和突发惊吓**，结局有 jump scare。光敏感人群及心脏病患者请勿观看。
- 右下角的「减弱模式」（或按 <kbd>Esc</kbd>）会关闭频闪、抖动和刺耳音效；系统开启「减少动态效果」时自动启用。
- 「声音」默认关闭，开启后才有音效。
- 页面会读取本机时钟、屏幕尺寸、浏览器类型，并感知标签页切换，用来生成台词。这些信息只在本机使用，不会上传。

## 运行

需要支持 WebGL2 的现代浏览器。直接用浏览器打开 `index.html`，或放到任意静态服务器、静态托管上均可。

在地址后加 `?p=0.8`（0 到 1）可以直接跳到对应的滚动进度。

## 结构

```
index.html      页面结构与全部文案（每个文字的“崩坏剧本”也在这里）
css/style.css   样式，以及各个崩坏阶段的主题
js/app.js       滚动驱动的崩坏、监控画面、走廊场景与结局
js/glsl.js      着色器：建筑外景、走廊与人形、胶片后期
js/engine.js    WebGL2 渲染引擎
js/audio.js     Web Audio 合成音效
```
